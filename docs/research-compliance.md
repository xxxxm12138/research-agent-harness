# 投研合规与发布规范

这个仓库来自一段一级市场 FA 机构的投研实习。公开的是方法与工具，不是任何项目信息。

## 什么永远不入库

| 类别 | 例子 |
|---|---|
| 交易材料 | BP、Term Sheet、增资协议、cap table、估值模型 |
| 会议材料 | Call Report、管理层访谈纪要、录音及转写 |
| 项目信息 | 在融项目清单、项目与机构的对应关系、融资诉求、内部评分 |
| 人物信息 | 真实创始人、同事、客户的姓名与评价 |
| 内部链接 | 在线文档、群聊、私有工作区或私有 artifact 的链接 |
| 本地痕迹 | 本机绝对路径、账号名、API key |

真实的 golden 样本、run log 与评测输入只放在私有工作区；本仓库里的 `examples/` 与评测用例全部虚构。

## 发布前检查

```bash
make check      # lint + tests + validate + scan
irh scan        # 只做合规扫描
```

`irh scan` 只扫描 git 会发布的文件（已跟踪 + 未被忽略），检查：

- **密钥**：API key、云服务与 GitHub token、私钥；
- **泄露**：本机绝对路径（如用户主目录）、在线文档与私有 artifact 链接；
- **保密文件类型**：pdf / doc(x) / ppt(x) / xls(x) / zip / 音频；
- **本地名单**：`.sensitive-terms.txt` 中的机构名、项目名、人名。名单文件被 gitignore，名字本身不会进仓库。普通行按不区分大小写的子串匹配；以 `re:` 开头的行是正则，适合同时是常用词的名字，例如 `re:\bAcme\b`（只匹配完整单词）。

CI 里跑的是不带名单的扫描；带名单的扫描在发布前本地运行。

## 研究规范（写进 Skill 与关口的那部分）

- **信息状态**：每条融资、估值、投资方、背景信息都带状态标签；标签不得强于所引来源（`EvidenceGate`）。
- **交叉验证**：`核实` 需要工商 / 公告记录，或两类独立的公开来源相互印证；两篇可能抄自同一通稿的报道不算。
- **时点**：只用决策日之前可得的信息（`TemporalGate`，工作区落盘时直接剔除）。
- **输出边界**：mapping 底稿只整理证据，不给投资或 FA 匹配建议，除非被明确要求（`IntentGate`）。
- **人物信息**：背调只用职业与公开信息；不收集住址、家庭、联系方式、私人社交账号，不对人格打分（`skills/founder-diligence/SKILL.md`）。
- **对外材料**：叙事稿与 BP storyline 不引用任何保密会议内容或未公开交易信息。
