# 项目筛选

**用途**：快速判断一个项目是否值得投入时间。供分析师自查思维完整性，或 AI 辅助整理 CR 中的关键维度
**核心原则**：这是 checklist，不是评分卡 — 帮你确认"该想的都想了"，不替你做判断

---

## 五个必问（30 秒版）

拿到一个新项目，依次回答。**答不上来本身就是信号**。

| # | 问题 | 答不上来意味着 |
|---|------|---------------|
| 1 | **赛道位置** — 这个赛道值不值得我们花时间？ | 你对赛道没有 view，先做赛道研究再看项目 |
| 2 | **团队匹配** — 这个问题需要什么人，眼前这个团队是吗？ | 你还没想清楚"什么样的人能赢" |
| 3 | **验证状态** — 核心假设验证到哪一步了？ | 信息不足以判断，需要补信息 |
| 4 | **竞争地位** — 在这个位置上，他们能赢/守得住吗？ | 你对格局没有认知 |
| 5 | **交易时机** — 现在 push forward 是好时机吗？ | 估值/轮次/市场情绪你没感觉 |

---

## 输出：三选一 + 下一步

不要输出分数。输出结论 + 动作。

### Push Forward
```
结论：Push Forward
理由：[一句话，为什么现在要推进]
下一步：[具体动作 — 安排 DD？发 TS？约管理层二面？]
时间：[什么时候之前完成]
```

### Watch
```
结论：Watch
理由：[一句话，为什么现在不推但不放弃]
等什么：[具体信号 — 什么条件满足后重新评估]
检查点：[什么时候回来看一次]
```

### Pass
```
结论：Pass
理由：[一句话，为什么不做]
翻转条件：[什么事情发生会让你重新考虑]
```

## 五个维度展开

### 1. 赛道位置

**该问的**：
- 这个赛道的终局是什么？（市场有多大、赢家通吃还是多强并存）
- Why now？为什么是现在而不是两年前/两年后？
- 我们在这个赛道有认知优势吗？（看过多少项目、有没有行业 view）

**常见陷阱**：
- "赛道很火" ≠ "赛道值得投"（火 = 估值贵 + 竞争激烈）
- "赛道太早" 不是拒绝理由 — 要说清楚"早"到什么程度、什么条件下不早了

---

### 2. 团队匹配

**该问的**：
- 这个问题最需要什么能力？（技术突破？商业化？融资？政府关系？）
- 眼前这个团队在**最需要的那个能力**上强不强？
- 缺口在哪？他们知道自己缺吗？有计划补吗？
- 核心成员一起干过事吗？还是新拼的？

**常见陷阱**：
- 名校/大厂光环 ≠ 执行力（问：他在大厂具体做了什么？是主导还是参与？）
- "连续创业者" — 上一个做多大？多久做到的？退出了吗？

---

### 3. 验证状态

**该问的**：
- 核心假设是什么？（技术可行性？客户付费意愿？成本结构？）
- 这个假设目前验证到哪一步了？

| 阶段 | 意味着 |
|------|--------|
| 纯 idea/PPT | 啥都没验证，只有团队信仰 |
| Demo | 技术可行性初步验证，商业化全未知 |
| POC（无付费） | 客户有兴趣但没掏钱 |
| POC（付费） | 客户愿意付钱试，但不知道能否规模化 |
| 规模化收入 | 核心假设基本成立 |

**常见陷阱**：
- "已有客户" — 是付费还是免费试用？金额多少？能续吗？
- "Demo 效果很好" — 谁评价的？什么场景下？受控环境还是真实环境？

---

### 4. 竞争地位

**该问的**：
- 直接对手是谁？（2-3 家，不是行业百科）
- 如果对手拿到大钱，这家会怎样？
- 客户选这家不选那家的依据是什么？
- 壁垒是什么？12 个月后这个壁垒会变强还是变弱？

**常见陷阱**：
- "没有直接竞争对手" — 通常意味着你没找到，或者赛道不存在
- "我们技术更好" — 客户选择不一定看技术（看关系、看价格、看集成成本）

---

### 5. 交易时机

**该问的**：
- 当前估值合理吗？（可比公司、可比轮次）
- 市场情绪怎么样？（这个赛道现在是热还是冷？）
- 这轮不做，下一轮估值会涨还是跌？
- 我们有没有竞争（其他 FA、其他投资人）？

**常见陷阱**：
- "估值便宜" ≠ "应该做"（便宜可能有原因）
- "估值贵" ≠ "不应该做"（如果半年后更贵，现在就是相对便宜）

## AI 辅助模式

当 AI 读完一份 CR 后，可以按以下格式整理信息（**不做判断，只整理维度**）：

```
## 项目筛选信息整理

### 赛道位置
- 赛道：[从 CR 提取]
- 行业关键变量：[从 CR 提取]
- ⚠️ 未覆盖：赛道终局判断、Why now

### 团队匹配
- 核心成员：[从 CR 提取]
- 能力分布：技术 [有/无]、商业化 [有/无]、融资 [有/无]
- ⚠️ 未覆盖：合作历史、缺口弥补计划

### 验证状态
- 当前阶段：[Demo / POC / 付费客户]
- 核心假设：[从 CR 提取]
- ⚠️ 未覆盖：假设验证的具体证据

### 竞争地位
- 已知竞对：[从 CR 提取]
- 差异点：[从 CR 提取]
- ⚠️ 未覆盖：客户选择依据、动态分析

### 交易时机
- 估值：[从 CR 提取]
- 轮次：[从 CR 提取]
- 竞争方：[从 CR 提取]
- ⚠️ 未覆盖：可比估值、市场情绪判断
```

**⚠️ 标记的含义**：这些是 CR 中没有覆盖到的信息，需要人工补充或在下次会议中追问。

---

## 使用场景

| 场景 | 怎么用 |
|------|--------|
| 新人拿到新项目 | 跑一遍 5 个问题 → 整理答案 → 和 senior 讨论 |
| Senior 快速过项目 | 30 秒回答 5 个问题 → Push/Watch/Pass |
| 团队周会过 pipeline | 每个项目用三选一格式汇报（结论+理由+下一步） |
| AI 辅助 | 读完 CR → 按 5 维度整理已知信息 + 标出信息缺口 |
