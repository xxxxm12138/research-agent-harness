# 术语对照表

> 中国有限责任公司语境下的股权融资核心术语。示例主体与数字均为虚构。

---

## 注册资本相关

| 术语 | 英文 | 定义 | 与 Cap Table 的关系 |
|---|---|---|---|
| **注册资本** | Registered Capital | 公司章程约定的全部股东认缴出资总额 | 相当于 Cap Table 的"总股数" |
| **认缴出资额** | Subscribed Capital | 股东承诺出资的金额（章程约定） | 决定持股比例的分子 |
| **实缴出资额** | Paid-in Capital | 股东已实际到账的金额 | 不影响持股比例，影响股东权利行使 |
| **资本公积** | Capital Reserve / Premium | 投资额中超出注册资本部分的溢价 | 投资额 − 认缴新增注册资本 = 资本公积 |
| **出资比例** | Shareholding Ratio | 该股东认缴出资额 / 注册资本总额 | 即 Cap Table 中的持股百分比 |

### 关键关系

```
投资额 = 认缴新增注册资本 + 资本公积

例（虚构）：示例创投投 $2M（≈RMB 14,200,000，汇率 7.10 为示例），认缴新增注册资本 ¥222,222
→ 资本公积 = 14,200,000 − 222,222 = ¥13,977,778
→ 持股比例 = 222,222 / (2,000,000 + 222,222) = 10.00%
```

## 估值相关

| 术语 | 英文 | 定义 | 计算关系 |
|---|---|---|---|
| **投前估值** | Pre-money Valuation | 本轮投资进来之前公司的估值 | 投前 = 投后 − 本轮投资额 |
| **投后估值** | Post-money Valuation | 本轮投资完成后公司的估值 | 投后 = 投前 + 本轮投资额 |
| **每股价格** | Price Per Share (PPS) | 本轮每 1 份注册资本对应的价格 | PPS = 投前估值 / 投前总注册资本（股数） |

### 关键关系

```
投后估值 = 投前估值 + 本轮总投资额
每股价格 = 投前估值 / 投前总股数（即上轮后的总注册资本）
新增注册资本 = 投资额 / 每股价格
新投资人持股% = 新增注册资本 / (原有总注册资本 + 新增注册资本)
             ≈ 投资额 / 投后估值（简化验证）
```

## 投资条款相关

| 术语 | 英文 | 定义 | Cap Table 处理 |
|---|---|---|---|
| **Pro Rata** | Pro Rata Right | 老股东在新轮次中按比例跟投的权利 | 新轮次 section 下独立一行，金额 = 维持原比例所需投入 |
| **反稀释** | Anti-dilution | Down round 时调整老投资人持股的保护条款 | 调整该投资人的每股价格（Full Ratchet 或加权平均） |
| **优先清算权** | Liquidation Preference | 退出时投资人优先于普通股东分配收益 | 不影响 Cap Table 比例，影响退出分配瀑布 |
| **Warrant** | Warrant / 认股权 | 以约定价格在未来认购股份的权利 | 行权前不计入持股，可单独做试算 sheet |
| **ESOP** | Employee Stock Option Pool | 员工期权池 | 通常作为独立股东行（通过持股平台） |

### Pro Rata 计算公式

```
目标：老投资人维持 X% 持股

Pro Rata 投资额 = X% × 新轮投后估值 − 老投资人现有股份价值
其中：现有股份价值 = 老投资人现有股数 × 新轮每股价格

简化：
Pro Rata 额 = (目标% × 投后 − 现有股数 × PPS_new)
```

## 持股载体相关

| 术语 | 定义 | 常见命名模式（虚构示例） |
|---|---|---|
| **自然人直接持股** | 创始人以个人名义直接持有公司股权 | 「创始人甲」 |
| **有限合伙持股平台** | 用 LP 架构间接持股，通常用于联创 / 员工 | 「示例一号科技合伙企业（有限合伙）」 |
| **ESOP 持股平台** | 专门用于员工期权的持股载体 | 「示例二号科技合伙企业（有限合伙）」 |
| **投资基金** | VC / PE 的投资主体 | 「示例创业投资合伙企业（有限合伙）」 |
| **海外 SPV** | 境外投资人用于持股的特殊目的主体 | 「Example Holdings VII Pte. Ltd.」 |

### 注意事项

- Cap Table 里必须用**法律主体全称**，不能简写为基金的品牌名。
- 有限合伙通常带"（有限合伙）"后缀。
- 同一家 VC 可能通过不同的基金实体投不同轮次。

## 中国 vs 美国体系对比

| 维度 | 中国有限公司 | 美国 Delaware C-Corp |
|---|---|---|
| 股权单位 | 注册资本（人民币金额） | Authorized Shares（股数） |
| 持股比例依据 | 认缴出资额占比 | 已发行股份数占比 |
| 面值 | 无固定面值概念 | Par Value（通常 $0.0001） |
| 增资方式 | 增加注册资本 | 发行新股 |
| 每股价格 | 投前估值 / 总注册资本 | 投前估值 / 已发行股数 |
| 取整 | 注册资本可有小数（但通常取整） | 股数必须为整数 |
