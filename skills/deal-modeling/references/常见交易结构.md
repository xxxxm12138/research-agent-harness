# 常见交易结构 — 公式速查

> 按场景列出标准计算公式，直接可用于Excel建模

---

## 1. 基础增资（最常见）

### 场景
单一投资人或多个投资人同一轮进入，统一估值、统一每股价格。

### Input
- `pre_money`: 投前估值
- `investment_i`: 各投资人投资额
- `shares_existing`: 投前总注册资本（股数）

### Formula

```
total_investment = SUM(investment_i)                    -- 本轮总投资
post_money = pre_money + total_investment              -- 投后估值
pps = pre_money / shares_existing                      -- 每股价格
new_shares_i = ROUND(investment_i / pps, 0)           -- 各投资人新增注册资本
shares_total = shares_existing + SUM(new_shares_i)     -- 投后总注册资本
pct_i = (existing_shares_i + new_shares_i) / shares_total  -- 各股东投后持股%
```

### 验证等式
```
investment_i / post_money ≈ new_shares_i / shares_total  （误差来自ROUND）
SUM(pct_i) = 100%
```

## 2. Pro Rata（老股东跟投维持比例）

### 场景
老投资人在新轮次行使Pro Rata权利，维持原有持股比例不被稀释。

### Input
- `target_pct`: 目标持股比例（=上轮持股%）
- `post_money_new`: 新轮投后估值
- `shares_old_investor`: 该投资人目前持有的注册资本

### Formula

```
-- 方法1：从比例倒推
pro_rata_amount = target_pct × post_money_new - shares_old_investor × pps_new

-- 方法2：等价简化（当没有其他特殊条款时）
pro_rata_amount = target_pct × total_new_round_investment / (1 - target_pct)
-- 注：方法2仅在该投资人是唯一Pro Rata参与者时精确

-- 新增注册资本
new_shares_prorata = ROUND(pro_rata_amount / pps_new, 0)
```

### 验证
```
(shares_old_investor + new_shares_prorata) / shares_total_after = target_pct
```

## 3. Anti-dilution（反稀释调整）

### 3a. Full Ratchet（完全棘轮）

最激进的保护。Down round时，老投资人的每股价格直接调整为新轮价格。

```
adjusted_pps = pps_new_round                           -- 直接等于新轮每股价格
adjusted_shares = original_investment / adjusted_pps   -- 重新计算股数
additional_shares = adjusted_shares - original_shares  -- 免费补偿的股数
```

### 3b. Weighted Average（加权平均）

更常见。按加权平均重新计算每股价格。

#### Broad-based（宽基，含ESOP等全部股份）
```
adjusted_pps = original_pps × (A + B) / (A + C)

A = 调整前总股数（fully diluted）
B = 新轮投资额 / 原每股价格（即按原价应发多少股）
C = 新轮实际发行股数（= 新轮投资额 / 新轮每股价格）
```

#### Narrow-based（窄基，仅计算优先股）
```
同上公式，但A仅计算优先股总数（不含普通股/ESOP）
```

## 4. ESOP Pool（员工期权池）

### 场景
在融资前或融资后设立/扩大ESOP池。

### 投前ESOP（Pre-money ESOP，更常见）
```
-- ESOP从投前稀释，投资人按投后比例不受影响
esop_pct = esop_pool / (shares_existing + esop_pool)
-- 创始人被稀释，投资人不被稀释
```

### 投后ESOP（Post-money ESOP）
```
-- ESOP从投后稀释，所有人（含新投资人）等比稀释
esop_pct_dilution = esop_pool / (shares_total + esop_pool)
```

### 中国有限公司ESOP实操
通常通过有限合伙持股平台预留：
```
-- 初始设立时直接分配注册资本给ESOP平台
-- 如：总注册资本200万，ESOP平台占30万（15%）
-- 后续员工通过合伙协议获得LP份额，不改变工商登记
```

## 5. Warrant（认股权证）

### 场景
投资人获得在未来以约定价格认购额外股份的权利。

### Input
- `warrant_amount`: Warrant对应的投资额上限
- `warrant_pps`: 行权价格（通常=本轮每股价格）
- `warrant_expiry`: 行权期限

### Formula（行权试算）
```
warrant_shares = ROUND(warrant_amount / warrant_pps, 0)
pct_after_exercise = (existing_shares + warrant_shares) / (total_shares + warrant_shares)
dilution_to_others = warrant_shares / (total_shares + warrant_shares)
```

### 注意
- Warrant行权前**不计入**持股比例
- 但做fully-diluted cap table时需要加入
- 通常单独sheet试算或在主表加"Fully Diluted"列

## 6. Liquidation Preference（清算优先权瀑布）

### 场景
公司退出（M&A/IPO）时的分配顺序。

### 常见结构：1x Non-participating

```
-- Step 1: 优先股投资人先拿回1x投资本金
senior_return = MIN(exit_proceeds, 1x × investment)
remaining = exit_proceeds - senior_return

-- Step 2: 优先股投资人选择：保留优先权 OR 转普通股按比例分
option_a = senior_return                              -- 保留优先权
option_b = pct_common × exit_proceeds                  -- 转换后按比例
investor_gets = MAX(option_a, option_b)
```

### 常见结构：1x Participating with Cap

```
-- Step 1: 先拿回本金
senior_return = investment × 1x

-- Step 2: 剩余按比例分（参与分配）
participation = pct × (exit_proceeds - total_senior)

-- Step 3: 不超过cap
investor_total = MIN(senior_return + participation, cap × investment)
```

## 7. IRR / MOIC（退出回报）

### Input
- `investment`: 投资金额
- `exit_value`: 退出时该笔投资的价值
- `years`: 持有年数

### Formula
```
MOIC = exit_value / investment                         -- 回报倍数
IRR = (exit_value / investment)^(1/years) - 1          -- 年化收益率（简化）

-- Excel精确IRR（考虑多次现金流）
IRR = XIRR(cashflows, dates)
```

### 行业基准
| 阶段 | 目标MOIC | 目标IRR |
|------|----------|---------|
| 种子 | 10-50x | 50%+ |
| A轮 | 5-20x | 40%+ |
| B轮 | 3-10x | 30%+ |
| Growth | 2-5x | 20%+ |

---

## 公式使用注意

1. **ROUND**：注册资本份额必须取整，用 `ROUND(..., 0)`
2. **精度**：百分比显示2位小数，但底层保留全精度
3. **循环引用风险**：Pro Rata计算时注意不要让total依赖pro_rata而pro_rata又依赖total
4. **验证**：每个公式写完后立即做交叉验证（投资额/投后≈持股%）
