# 中国有限公司 — 股权计算规则

> 一级市场早期项目绝大多数是中国有限责任公司（或 VIE 架构下的境内运营主体）。本文档梳理与 Cap Table 直接相关的法律框架。示例主体与数字均为虚构，完整算例见 `skills/deal-modeling/references/worked-example.md`。

---

## 基本法律框架

### 公司类型与持股单位

| 类型 | 股权单位 | 持股依据 | 适用场景 |
|---|---|---|---|
| **有限责任公司** | 注册资本（人民币金额） | 出资比例 | 早期创业公司（绝大多数情况） |
| 股份有限公司 | 股份数（股） | 持股数 | 拟 IPO 公司（改制后） |

### 有限公司核心规则（《公司法》）

1. **持股比例 = 认缴出资额 / 注册资本总额**
   - 按认缴，不按实缴
   - 章程另有约定的除外（融资场景极少见）
2. **增资 = 增加注册资本**
   - 新投资人认缴新增注册资本 → 持股比例变化
   - 需要全体股东同意（或按章程约定）
   - 办理工商变更登记
3. **溢价增资**
   - 投资额超过新增注册资本的部分计入资本公积
   - 例：投 $2M（≈RMB 1,420 万，汇率 7.10 为示例），认缴新增注册资本仅 ¥222,222
   - 资本公积 = 14,200,000 − 222,222 = ¥13,977,778

## Cap Table 计算方法（有限公司）

### 核心公式

```
每股价格(PPS) = 投前估值(USD) / 投前总注册资本(RMB 份额)
新增注册资本 = 投资额(USD) / PPS
投后持股%   = (原注册资本 + 新增注册资本) / 投后总注册资本
```

### 注意：混合币种问题

中国有限公司的注册资本以人民币计，VC 估值通常以美元计。处理方式：

**方法 A（常用）**：全部以美元估值为基础计算比例，注册资本金额只用于法律登记。

```
持股% = 投资额(USD) / 投后估值(USD)
注册资本份额 = ROUND(总注册资本 × 持股%, 0)  -- 倒推
```

**方法 B（严格）**：以注册资本为基础。

```
PPS = 投前估值(USD) / 投前总注册资本
新增注册资本 = ROUND(投资额 / PPS, 0)
持股% = 新增注册资本 / (原有 + 新增)
```

**实操**：团队模板用方法 B（先算 PPS 再算注册资本），验证时用方法 A 交叉检验。

## 注册资本 vs 实缴 vs 认缴

### 时间线

```
签协议时 → 认缴（承诺出资，工商登记变更）
打款时   → 实缴（资金到账）
```

### Cap Table 关注哪个？

**认缴。** Cap Table 反映的是认缴出资比例，不是实缴。原因：

- 持股比例在认缴时即确定；
- 实缴期限可以较长（新《公司法》规定有限公司认缴出资原则上 5 年内缴足）；
- 投资人通常要求尽快实缴以保护权利。

### 常见坑

| 情况 | 正确处理 |
|---|---|
| 股东认缴 100 万但只实缴了 30 万 | Cap Table 仍按 100 万计算比例 |
| 增资协议约定分期出资 | Cap Table 按总认缴额计算，不按已到账 |
| 协议约定"实缴后生效" | 这是交割条件，不影响 Cap Table 计算 |

## 有限合伙持股平台

### 为什么用有限合伙？

1. **税收穿透**：避免公司制的双重征税。
2. **控制权集中**：GP（通常是创始人）掌握决策权。
3. **灵活调整**：LP 份额变更不需要标的公司做工商变更。

### 在 Cap Table 中的体现（虚构示例，投后）

```
示例科技（上海）有限公司（有限责任公司）
├── 创始人甲（自然人直接持股）— 54.00%
├── 示例一号科技合伙企业（有限合伙，联创持股平台）— 22.50%
│   ├── GP: 创始人甲
│   └── LP: 联创 A、联创 B、联创 C…
├── 示例二号科技合伙企业（有限合伙，ESOP 平台）— 13.50%
│   ├── GP: 创始人甲
│   └── LP: 员工（未来授予）
└── 示例创业投资合伙企业（有限合伙，投资主体）— 10.00%
```

### Cap Table 只看第一层

- Cap Table 记录的是直接持有标的公司股权的主体；
- 不穿透有限合伙的 LP 结构；
- 股东名称 = 合伙企业全称（如「示例一号科技合伙企业（有限合伙）」）。

## ESOP 在有限公司的处理

### 常见方式

1. **代持**：创始人代持 ESOP 份额，未来逐步过户。
2. **持股平台**：设立有限合伙，员工作为 LP 加入。
3. **预留但未发行**：章程约定预留比例，实际授予时再增资。

### Cap Table 处理

- 无论哪种方式，ESOP 在 Cap Table 中都作为独立一行；
- 持股平台用平台全称（如「示例二号科技合伙企业（有限合伙）」）；
- 代持则注明"XX 代持（ESOP 预留）"。

## 工商登记 vs Cap Table

| 维度 | 工商登记 | Cap Table |
|---|---|---|
| 更新频率 | 变更决议后 30 日内申请变更登记 | 实时 / 每轮更新 |
| 精度 | 注册资本精确到元 | 可有小数（但 ROUND 取整） |
| 内容 | 仅注册资本和出资比例 | 含估值、每股价格、投资额 |
| 法律效力 | 对抗第三人 | 内部管理和投资人沟通用 |

### 注意

- Cap Table 的注册资本数字最终需要与工商登记一致。
- 如果 ROUND 结果与协议约定的精确数字不同，以协议为准：该单元格改为 key-in（并注明协议出处），不要让公式算出一个差 1 的数。

## 常见错误防范

| 错误 | 正确做法 |
|---|---|
| 把注册资本单位搞成"万元" | 仔细看协议，通常写"人民币 XX 元" |
| 用实缴金额算比例 | 用认缴金额 |
| 持股平台简写为个人名字 | 用工商全称 |
| 忽略资本公积 | 投资额 − 新增注册资本 = 资本公积（不影响比例，但需理解） |
| 美元 / 人民币混用不标注 | 每列标注币种，汇率单独一个单元格 |
