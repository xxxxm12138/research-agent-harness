# Cap Table 格式模板（house template）

> 团队内部 cap table 的通用格式约定。具体项目的模板文件属于保密材料，不入库；这里只记录可复用的结构规则。

---

## 视觉格式

| 项 | 约定 |
|---|---|
| 字体 | Times New Roman 11pt |
| 表头 | 灰色背景、居中、加粗 |
| 边框 | medium weight、全边框 |
| 金额 | 千分位 `#,##0` |
| 百分比 | 两位小数 `0.00%` |
| 对齐 | 数字右对齐、文本左对齐 |
| Input 单元格 | 蓝色字体 |

---

## 表格结构（每轮一组列）

```
| 股东 | 初始注册资本 | 初始% | 本轮投资额(USD) | 本轮新增注册资本 | 本轮后总注册资本 | 本轮后% |
```

每新增一轮，向右扩展 4 列：`投资额 | 新增注册资本 | 累计注册资本 | 累计%`。

---

## 区块布局与 Input / Formula 位置

| 区块 | 内容 | 类型 |
|---|---|---|
| 表头区 | 公司全称、币种、汇率单元格 | 汇率为 Input |
| 本轮投资额区 | 各投资人本轮投资金额 | Input |
| 估值区 | 投前估值 | Input（写成 `=18000000` 这类带等号的常数，实质仍是 Input） |
| 估值区 | 投后估值 = 投前 + 本轮合计 | Formula |
| 估值区 | 每股价格 = 投前估值 / 投前总注册资本 | Formula |
| 原有股东区 | 各股东投前注册资本 | Input |
| 原有股东区 | 新增 = `ROUND(投资额 / 每股价格, 0)`；累计 = 上轮累计 + 本轮新增；% = 本行累计 / 总计行累计 | Formula |
| 新投资人区 | 同上 | Formula |
| 小计 / 总计 | 小计 = `SUM(section 内各行)`；总计 = 原有股东小计 + 新投资人小计 | Formula |
| 验证行 | 关键等式的差值（应 = 0） | Formula |

---

## 底部汇总表（如需要）

- 合并同一投资人跨轮的持股（同一机构可能通过不同基金实体投不同轮，汇总时按机构合并、明细保留实体全称）。
- 汇总表全部用公式引用主表，不重新 key-in。

一个按本模板填好的虚构算例见 `skills/deal-modeling/references/worked-example.md`。
