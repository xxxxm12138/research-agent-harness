# 虚构算例：一轮美元增资的 Cap Table

> 所有主体与数字均为虚构，用于演示 Input / Formula 规则与验证步骤。`tests/test_examples.py` 会解析下面两张表并校验算术，改动数字时测试会提醒你保持自洽。

## 背景

- 标的：示例科技（上海）有限公司，中国有限责任公司，投前注册资本 ¥2,000,000。
- 本轮：示例创业投资合伙企业（有限合伙）以投前估值 $18,000,000 投资 $2,000,000。
- 计算体系：注册资本制，方法 B（先算每股价格，再算新增注册资本），用方法 A（投资额 / 投后估值）交叉检验。

## 关键参数

| 项目 | 值 | 类型 | 公式 |
|---|---|---|---|
| 投前估值（$） | 18,000,000 | Input | — |
| 本轮投资额（$） | 2,000,000 | Input | — |
| 汇率（示例） | 7.10 | Input | — |
| 投前注册资本（¥） | 2,000,000 | Input | — |
| 投后估值（$） | 20,000,000 | Formula | 投前估值 + 本轮投资额 |
| 每股价格（$ / ¥1 注册资本） | 9.00 | Formula | 投前估值 / 投前注册资本 |
| 新增注册资本（¥） | 222,222 | Formula | ROUND(本轮投资额 / 每股价格, 0) |
| 资本公积（¥） | 13,977,778 | Formula | 本轮投资额 × 汇率 − 新增注册资本 |

## Cap Table

| 股东 | 类型 | 投前注册资本（¥） | 投前% | 本轮投资额（$） | 新增注册资本（¥） | 投后注册资本（¥） | 投后% |
|---|---|---|---|---|---|---|---|
| 创始人甲 | 自然人 | 1,200,000 | 60.00% | — | — | 1,200,000 | 54.00% |
| 示例一号科技合伙企业（有限合伙） | 联创持股平台 | 500,000 | 25.00% | — | — | 500,000 | 22.50% |
| 示例二号科技合伙企业（有限合伙） | ESOP 平台 | 300,000 | 15.00% | — | — | 300,000 | 13.50% |
| 示例创业投资合伙企业（有限合伙） | 投资基金 | — | — | 2,000,000 | 222,222 | 222,222 | 10.00% |
| 合计 | — | 2,000,000 | 100.00% | 2,000,000 | 222,222 | 2,222,222 | 100.00% |

## 验证

| 检查 | 结果 |
|---|---|
| 投后% 加总 | 100.00% |
| 投前 + 本轮 = 投后 | 18,000,000 + 2,000,000 = 20,000,000 |
| 投资额 / 每股价格 ≈ 新增注册资本 | 2,000,000 / 9.00 = 222,222.2 → ROUND = 222,222（误差 < 1） |
| 方法 A 交叉检验 | 投资额 / 投后估值 = 10.00%；新增 / 投后总注册资本 = 222,222 / 2,222,222 = 10.00% |
| 稀释合理性 | 原股东同比稀释 10%，处于种子 / A 轮常见区间 |
| 资本公积 | 2,000,000 × 7.10 − 222,222 = 13,977,778（不影响比例） |

若协议约定的认缴出资额与 ROUND 结果不同（例如差 1），以协议为准：该单元格改为 key-in，并注明协议条款出处。
