# 大厂格局边界写法

Pitch 前 Mapping 中「大厂前沿部门」章节的标准写法。

---

## 章节导读（复制到报告）

```markdown
**本章导读**：看大厂前沿，核心不是找「融资对标」，而是判断三件事：
① 某条技术线是否已被大厂全量覆盖；
② 人才外流是否指向下一批创业标的；
③ 大厂是客户 / 战投，还是商业化替代者。
```

---

## 单家模板（三段式 + 组织背景）

```markdown
### [序号]. [公司 / 部门]

- **组织背景**：[体内位置；是否独立融资；与 Pitch 标的的关联]

- **在做什么**：
    - [技术线名称 + 代表架构 / 产品]
    - [近 12-18 个月的公开进展：论文 / 产品 / 开源，带日期]
    - [路线演变，如有]

- **做得如何**：[国内 / 全球梯队]；[公开痛点或瓶颈]

- **对创业的意义**：
    - [ ] cap table 竞品？（是 / 否 + 说明）
    - [ ] 商业化替代风险？（是 / 否 + 说明）
    - [ ] 客户 / 战投角色？（是 / 否 + 举例）
    - [ ] 人才外流信号？（跟踪价值）
```

---

## 三种关系必须分开写

| 关系类型 | 定义 | 写法示例 |
|---|---|---|
| **cap table 竞品** | 同轮次争夺同一批投资人的创业标的 | 「一级市场的对比对象仍是同赛道的创业公司 A、B，而不是大厂」 |
| **商业化替代** | 大厂自研落地，压缩创业公司的客户空间 | 「某大厂已全栈自研同类系统 → 面向大客户的商业化替代风险上升」 |
| **客户 / 战投** | 买方或战略投资方 | 「下游整机厂、车企更可能是创业公司的客户或战投，而非竞争对手」 |

> 同一段内不要混用三种关系。技术竞争 ≠ 融资竞品。

---

## 章节结论模板

```markdown
**本章结论**：大厂 [能力域] 布局全面，且在 [时间] 加速，但多数锁在体内、不独立融资。
创业差异化不在「大厂没做」，而在：
**场景专注**（真实闭环 vs 通用能力）、
**股权弹性**（机构能进的 cap table）、
**人才密度**、
**单一技术轴叙事的深度**。
大厂最有价值的两个信号：
① 客户 / 战投角色；
② 人才外流方向。
```

---

## 质量自检

```
□ 每家独立成段，而非压缩成三列表格
□ 三种竞争关系分开表述
□ 「做得如何」有梯队判断，而非只列项目名
□ 至少 1 家标注人才外流（talent pipeline）信号
□ 没有把大厂体内项目当作创业公司的融资对标
```
