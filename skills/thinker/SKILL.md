# Thinker — AI 磨刀石

> 来源说明：本 Skill 改编自一篇关于"把 AI 当磨刀石而不是大脑"的公开文章，ADAS、圆桌质询、魔鬼拷问等方法出自原文；这里是面向投研场景的提炼与改写，原文版权归原作者。

**核心理念**：不要把 AI 当成替你决策的"大脑"，而要把它当成帮你磨刀的"磨刀石"。判断必须是你的，AI 只提供原材料和质疑。

---

## 两阶段分离（最重要）

| 阶段 | 任务 | AI 角色 | 人的角色 |
|---|---|---|---|
| **Insight（洞察）** | 看清楚世界现在什么样 | 用 ADAS 整理原材料 | 提炼洞察，写初始判断 |
| **Strategy（策略）** | 决定我们要做什么 | 圆桌质询、魔鬼拷问 | 做最终判断 |

**禁止**：在 Insight 未完成时让 AI 回答"核心问题是什么""应该投 / 不投"。AI 的结论会成为锚点，后续思考都在它的框架里打转。

---

## 执行流程（内化，不单独交付）

```
1. ADAS 原材料
   关联 → 拆解 → 对齐 → 总结
   只要事实，不要建议（Prompt 末尾加「不做策略建议」）

2. 初始判断（人 / agent 先写）
   「基于我看到的这些，我认为核心问题是______，因为______。」

3. 圆桌质询
   多视角质疑：问题定义是否准确？有没有明显盲点？

4. 魔鬼拷问
   从历史 / 现实 / 终局三个维度攻击这个判断

5. 形成地图后再写作
   你定框架，AI 填结构与证据
```

---

## ADAS 四步

| 步骤 | 做什么 | Prompt 要点 |
|---|---|---|
| **A**ssociate 关联 | 找到与问题相关的所有事物 | 梳理竞品 / 玩家 / 趋势 |
| **D**econstruct 拆解 | 拆开看每个玩家的核心差异化 | 每个玩家靠什么赢 |
| **A**lign 对齐 | 横向对比，找趋同与分歧 | 哪些维度趋同、哪些分歧 |
| **S**ummarize 总结 | 归纳主流打法 / 规律 | 只做归纳，不做判断 |

**关键 Prompt 后缀**：「只用公开可查证的信息，不做策略建议，不判断哪种打法更好。」

## 在投研任务中怎么用

| 任务类型 | Thinker 用法 |
|---|---|
| 赛道 Mapping | ADAS 整理竞品 → 写初始判断 → 魔鬼拷问后定核心论点 |
| 人物背调 | ADAS 整理论文 / 公开信息 → 初始识人判断 → 设计访谈问题 |
| Lab 档案 | ADAS 整理技术 / 融资信息 → 初始 Push / Watch / Pass → 质疑后写作 |
| 混合任务 | 每个子任务独立走一遍 |

---

## 铁律

- Insight 阶段 AI 只给原材料，不给结论。
- 初始判断必须先于任何 AI 策略建议。
- 魔鬼拷问的产出是"判断是否需要修正"，不是"AI 替你做决定"。
- 一级市场判断高度主观，AI 无法替代投资嗅觉。
