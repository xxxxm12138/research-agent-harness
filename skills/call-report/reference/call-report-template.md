# Call Report 标准模板

> 按此模板组织信息。结构可根据公司阶段精简（见下方精简规则）。示例内容均为虚构。

---

## 报告结构

```
Call Report of [公司名称]
会议时间: [YYYY 年 M 月 DD 日]

[表头信息卡]（Tab 分隔）
企业名称            [公司名称]
企业业务简述        [一句话核心定位]
客户参会人及职级    [姓名（学历 / 身份简写）]
项目负责人          [内部负责人]
其他参会人          [其他参会同事]
客户所处行业        [行业标签]
客户分级            [1-5 分]
客户交易诉求        私募融资
潜在交易币种及规模  [金额]
项目来源            内部：[人名] / 外部：[来源]
竞争FA              [FA 名称 / 无]

附录. 打分表
考虑因素 | 评价维度 | 分数（1–5）
...

[正文]
一．公司业务
二．行业情况
三．本轮融资需求 / 交易架构安排
（中后期项目增加：竞争优势、潜在风险因素）
```

---

## 精简规则

| 公司阶段 | 正文章节 |
|---|---|
| **种子 / 天使** | 一．公司业务（团队 + 技术 + 产品进展）→ 二．行业情况（关键变量）→ 三．融资需求 |
| **Pre-A / A 轮** | 一．公司业务 → 二．行业情况（含竞争格局）→ 三．竞争优势 → 四．潜在风险 → 五．融资需求 |
| **B 轮+** | 全部章节 + 运营及财务数字 |

**表头和打分表无论阶段都必须 100% 填写。**

---

## 各章节记录规范

### 表头信息卡

逐项填写，不跳过。🤖 表示可从录音提取，👤 表示需项目负责人手动补填。

| 字段 | 说明 | 来源 |
|---|---|:---:|
| 企业名称 | 公司全称 | 🤖 |
| 企业业务简述 | 一句话说清"做什么"，不用形容词。如"端侧 AI 陪伴硬件——面向独居青年的语音陪伴设备" | 🤖 |
| 客户参会人及职级 | 格式：职位 + 姓名（学历简写）。如"联合创始人 & CEO 张三（XX 大学 PhD）" | 🤖 |
| 项目负责人 | 内部负责人姓名 | 👤 |
| 其他参会人 | 其他参会同事 | 👤 |
| 客户所处行业 | 行业标签 | 🤖 |
| 客户分级 | 必填数字（1–5），不留空 | 👤 |
| 客户交易诉求 | 通常为"私募融资" | 🤖 |
| 潜在交易币种及规模 | 写具体金额，如"1000 万美元"，不写"待定" | 🤖 |
| 项目来源 | 写"内部：[人名]"或"外部：[来源]" | 👤 |
| 竞争 FA | 有就写名称，没有写"无"或"/" | 👤 |

### 打分表

- 7 个维度逐项打分，1–5 分（可用 0.5 分）。
- 不适用的写 NA。
- 不需要逐项写评分依据。
- 参考 `skills/call-report/reference/scoring-anchors.md` 校准分数锚点。

---

### 一．公司业务

#### 1. 团队情况

**格式**：每人一条 bullet：「职位 + 姓名：学历，关键经验，代表成果」。

```
示例（虚构）：
a. 联合创始人 & CEO 张三：海外高校博士在读，入学前有 3 年工业界视觉算法经验；代表工作为一个 7B 参数的视频预测模型（50 万+条交互轨迹训练）和一个 15 FPS 的实时控制方法
```

**记什么**：

- 每人 1–2 句：学历 + 关键工作经验 + 代表成果（带数字）
- 团队规模 + 地域分布
- 导师资源（如有）：姓名、头衔、对项目的实际价值
- 人才策略（如有独特逻辑）

**不记什么**：

- 写报告者的评价（"商业化能力空白""成熟度待验证"）
- 完整简历（审稿经历、毕业年份等无关细节）
- 导师的论文数 / h-index
- 与能力无关的个人信息（见 `skills/founder-diligence/SKILL.md` 的边界表）

#### 2. 技术路线与产品

**技术路线**：

- 核心定位一句话
- 技术差异点 2–3 条（每条一句核心，展开不超过两句）
- 创始人对竞争者路线的判断标注为"认为…"

**数据策略**（如适用）：

- 目标数据量 + 时间
- 来源配比（如"20% 自研采集，80% 众包"）
- 不用什么数据 + 原因（一句）
- 当前数据量
- 数据成本

**产品 / 业务进展**：

- 公司成立时间
- 当前阶段（Demo / POC / 付费客户）
- 应用方向的探索结论
- 长期愿景（一句）

**不记什么**：论文摘要式的技术展开；技术名词堆砌而不解释选择；写报告者的技术评价。

#### 3. 商业模式（如有明确模式）

早期项目可压缩为产品进展里的一句（如"偏向 2C，承载形态仍在探索"）。

---

### 二．行业情况

#### 早期项目（种子 / 天使）：只写"行业关键变量"

格式：3–5 个影响该公司的关键变量，每个一句。

```
示例（虚构）：
a. 算力成本：当前月均算力成本约 20 万（8 台机器，云上租赁），决定 10 万小时数据目标能否达成
b. 供应链成熟度：核心传感器良率不稳定，模型需要能够"兜底"硬件缺陷
```

**不记什么**：赛道百科式介绍；竞争对手逐家展开（早期项目可省略）；宏观政策的通用结论；"观点一 / 观点二 / 创始人立场"这类赛道叙事分歧讨论。

#### 中后期项目（A 轮+）：增加竞争格局

- 直接对手 2–4 家，每家一句话差异
- 行业共识和分歧

---

### 三．竞争优势（中后期项目）

早期项目省略此章节——技术差异点已在正文体现。

中后期项目列 2–4 条，每条格式：「优势点 + 相比谁 + 护城河强度」。

---

### 四．潜在风险因素（中后期项目）

早期项目省略此章节——风险由打分表分数隐含。

中后期项目按四类各写一条：技术风险 / 竞争风险 / 执行风险 / 时机风险。

---

### 五．本轮融资需求 / 交易架构安排

**格式**：压缩为 2–4 条 bullet。

**必须包含**：

- 历史融资（轮次 + 投资方 + 金额 + 投后估值），一句话
- 本轮状态（金额 + 投后 + 进度）
- 后续融资规划（下一轮目标）
- 公司架构（JV / VIE / 开曼 / 境内，注册地）

**不记什么**：FA 内部推进细节（覆盖了多少家机构、谁否决了）；战投名单的内部讨论；建议性语言（"建议先转化一轮美元财务基金"）。

```
示例（虚构）：
1. 种子轮两家人民币基金合计 ~3kw 人民币，投后 ~3000 万美元；本轮美元基金交割中，投后 ~8000 万美元；计划同步启动下一轮，目标投后 1.5-2 亿美元
2. 公司架构：境内主体，暂未搭建境外架构
```

## 语言处理速查（示例均为虚构）

| 原始材料中出现 | 处理方式 | 理由 |
|---|---|---|
| "这就跟我们小时候搭积木一样" | 删除 | 纯闲聊比喻 |
| "这事很难" | 保留 | 简洁表达行业判断 |
| "模型能力强到即使硬件很烂也能稳定可控" | 保留 | 精准传达技术目标 |
| "是研究诚实性的正向信号" | 删除 | 写报告者的主观评价 |
| "领导还没看" | 删除 | FA 内部操作 |
| "完全没有想好" | 压缩为"方向尚未明确" | 去口语化但保留信息 |
| "客户其实就想要个能用的，demo 再炫也没用" | 精简为"客户优先看可用性而非 demo 效果" | 比喻无增量 |
| "年初还是 60 分，现在已经 95 分了" | 精简为"榜单分数已接近饱和" | 保留核心信息，删去展开 |
| "3000 万人民币" 或 "3kw 人民币" | 均可 | 行内简写可接受 |
| "Latent space" | 保留英文 | 技术术语的标准写法 |
| "打工加合作" | 改为"合作" | 口语无信息增量 |
